# RLCPP

A Pong game written in C++ with raylib. Menu, 2 players or 1 vs CPU, paddle turbo, win by a 3 point lead.

## Build and run

```
cmake -S . -B build
cmake --build build
./build/bin/RaylibCPP
```

## Controls

Menu and pause: arrows to move, Enter to select.

- Player 1: W / S to move, Space for turbo
- Player 2: Up / Down to move, Right Shift for turbo
- P: pause
- R: restart match
